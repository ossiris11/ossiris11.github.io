# Дизайн-система OSTAP TV (Golden Cinema)

Документ регламентирует визуальные стандарты, дизайн-токены, типографику, анимации и принципы верстки интерфейса **OSTAP TV**.

---

## 1. Концепция бренда и философия стиля

Интерфейс **OSTAP TV** выполнен в премиальной стилистике **Golden Cinema**:
* **Атмосфера:** Дорогой частный кинозал, бархатный глубокий обсидиановый фон и акценты полированного кинематографического золота.
* **Строгое правило брендинга:** Во всех пользовательских интерфейсах, текстах, уведомлениях и логах используется исключительно название **OSTAP TV**. Упоминание любых сторонних названий или старых платформ строго запрещено.

## 3. Типографика

* **Семейство шрифтов:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`.
* **Масштабируемость:** Все размеры элементов и шрифтов задаются в относительных единицах `em` и `rem`, что обеспечивает идеальное масштабирование интерфейса как на экране смартфона, так и на 85-дюймовом 4K-телевизоре (10-foot UI).

## 4. Спецификация компонентов

### 4.1. Боковые выдвижные панели (`.selectbox`, `.settings`)

> [!IMPORTANT]
> **Критическое правило трансформации боковых панелей:**
> Базовое позиционирование боковой панели в стилях: `position: fixed; top: 0; left: 100%; width: 35%;`.
> Для открытия панель сдвигается на экран влево:
> `transform: translate3d(-100%, 0, 0) !important;`
> **Ни в коем случае нельзя вешать на `.selectbox__content` анимации со смещением `translate3d(0, 0, 0)`, иначе панель улетит за правый край экрана!**

```css
/* Пример эталонного стиля селектора OSTAP TV */
.selectbox {
    z-index: 10005 !important;
}

.selectbox__layer {
    z-index: 10005 !important;
    background: rgba(0, 0, 0, 0.6) !important;
    backdrop-filter: blur(8px) !important;
    -webkit-backdrop-filter: blur(8px) !important;
}

.selectbox__content {
    z-index: 10006 !important;
    background: rgba(14, 16, 22, 0.96) !important;
    border-left: 1.5px solid rgba(212, 175, 55, 0.3) !important;
    box-shadow: -15px 0 45px rgba(0, 0, 0, 0.9), -2px 0 15px rgba(212, 175, 55, 0.15) !important;
    backdrop-filter: blur(20px) !important;
    -webkit-backdrop-filter: blur(20px) !important;
}

@media screen and (min-width: 481px) {
    body.selectbox--open .selectbox__content {
        transform: translate3d(-100%, 0, 0) !important;
        visibility: visible !important;
        opacity: 1 !important;
    }
}
```

### 4.2. Элементы списка в меню (`.selectbox-item`)
* В пассивном состоянии: скругление `10px`, аккуратный внутренний отступ, плавный переход `0.16s`.
* В состоянии фокуса (`.focus`):
  * Заливка: фирменный золотой градиент `var(--ostap-gold-gradient)`.
  * Цвет текста: глубокий обсидиан `#090A0D`.
  * Эффект свечения: `box-shadow: 0 4px 18px rgba(212, 175, 55, 0.35)`.

### 4.3. Карточки фильмов и сериалов (`.card`)
* Скругление углов постеров: `12px`.
* Тонкая золотая рамка при наведении / фокусе пульта ДУ.
* Масштабирование: плавный подъем карточки `scale3d(1.05, 1.05, 1)` с аппаратным ускорением GPU (`transform: translateZ(0)`).

### 4.4. Панель видеоплеера (`.player-panel`)
* Полупрозрачный стеклянный фон (Dark Obsidian Glass).
* Золотая полоса прогресса воспроизведения (таймлайн).
* Кнопки управления: неоновые золотые пиктограммы с мягким откликом при нажатии.

## 5. Производительность на телевизорах (60 FPS Smart TV Engine)

Телевизоры имеют ограниченные ресурсы графического процессора. Для предотвращения микрофризов (Zero-Jank):
1. **Только Composite-свойства:** для всех анимаций перемещения и масштабирования используются исключительно `transform: translate3d()` и `opacity`.
2. **Аппаратные слои:** на элементы с частым фокусом накладывается `transform: translateZ(0)` и `backface-visibility: hidden`.
3. **Ограничение Blur:** на старых моделях ТВ тяжелые фильтры `backdrop-filter: blur(...)` отключаются или заменяются плотным полупрозрачным цветом `rgba(14, 16, 22, 0.96)`.
