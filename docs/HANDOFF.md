# Руководство по передаче проекта (Handoff Guide для AI и разработчиков)

> [!NOTE]
> Этот документ предназначен для AI-моделей и инженеров, продолжающих разработку, оптимизацию и развитие проекта **OSTAP TV**. В нем собраны ключевые архитектурные решения, история устраненных багов, критические подводные камни и бэклог задач.

---

## 1. Базовые правила и ограничения проекта

1. **Строгий брендинг — OSTAP TV:**
   * Интерфейс, тексты, уведомления (`Noty.show`), логи и документация должны строго использовать название **OSTAP TV**.
   * Запрещено отображать или использовать в пользовательском интерфейсе любые сторонние названия («Lampa» и т.п.).
2. **Дизайн-стиль — Golden Cinema:**
   * Фон: глубокий обсидиановый (`#090A0D`).
   * Акценты: теплое благородное золото (`#D4AF37`, градиент `#ECC870` -> `#D4AF37` -> `#AA820A`).
3. **Совместимость с пультами Smart TV и мышью:**
   * Все новые интерактивные элементы должны иметь класс `.selector` для интеграции в систему пространственной навигации `Navigator` и поддерживать как событие `'hover:enter'`, так и `'click'`.

## 3. Критические нюансы (Gotchas & Watchouts)

1. **Позиционирование боковых шторок (`.selectbox__content`, `.settings__content`):**
   * Всегда помните, что эти элементы имеют `position: fixed; top: 0; left: 100%;`.
   * Чтобы шторка была видна, на ней **обязан** быть `transform: translate3d(-100%, 0, 0)`.
   * Никогда не применяйте к ним анимации с конечной точкой `translate3d(0, 0, 0)` на десктопе!
2. **Деплой файлов стилей по SCP:**
   * При загрузке `custom.css` целевой путь на сервере — `/var/www/ostap-tv/css/custom.css` (в подпапку `css/`, а не в корень).
3. **Проверка синтаксиса перед деплоем:**
   * Всегда запускайте `node -c app.min.js`. Любая лишняя скобка сломает приложение на смарт-телевизорах.
4. **Порт TorrServer для плеера:**
   * В плеер потоки должны передаваться через прокси-порт `:8090`, а не напрямую `:8091`.

## 4. Бэклог задач для дальнейшего развития (Roadmap)

### Приоритет 1 (Высокий)
* [ ] **Опциональное серверное транскодирование AC-3 -> AAC:**
  * Реализовать на VPS легковесный микросервис (на Go или Python/FFmpeg), который по параметру `?transcode=audio` на лету конвертирует неподдерживаемую звуковую дорожку AC-3 в AAC stereo/5.1 для пользователей Chrome и мобильного веба без потери качества видео.
* [ ] **Синхронизация выбора аудиодорожек на Smart TV:**
  * Протестировать и отладить передачу выбранного аудио-индекса в Tizen `webapis.avplay.setSelectTrack('AUDIO', idx)` и webOS Luna API.

### Приоритет 2 (Средний)
* [ ] **Стилизация субтитров в фирменном стиле:**
  * Добавить возможность выбора размера, цвета (золотой/белый) и обводки субтитров в плеере.
* [ ] **Умный кэш метаданных TMDB:**
  * Локальное кэширование популярных подборок в IndexedDB для мгновенного запуска приложения на ТВ со слабым интернетом.

### Приоритет 3 (UX & Дизайн)
* [ ] **Голосовой поиск:**
  * Интеграция Web Speech API для ввода поисковых запросов голосом с пульта ДУ или смартфона.
* [ ] **Мобильный PWA режим:**
  * Полноэкранный запуск на iOS / Android без полос браузера («Добавить на экран Домой»).
